# TP53 mammal example data

`tp53_mammals.fasta` contains three curated NCBI RefSeq protein records retrieved through NCBI E-utilities on 2026-10-01:

| FASTA identifier | Taxon | NCBI record |
|---|---|---|
| NP_000537.3 | Homo sapiens | https://www.ncbi.nlm.nih.gov/protein/NP_000537.3 |
| NP_035770.2 | Mus musculus | https://www.ncbi.nlm.nih.gov/protein/NP_035770.2 |
| NP_112251.2 | Rattus norvegicus | https://www.ncbi.nlm.nih.gov/protein/NP_112251.2 |

Accessions and versions are retained in FASTA headers. This is a small reproducible software demonstration, not a comprehensive or orthology-curated evolutionary study. For production research, define taxa and isoforms explicitly, assess orthology and sequence quality, and cite the underlying database records.
